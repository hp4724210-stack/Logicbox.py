# Pattern Generator and Number Analyzer

## 📌 Description

This is a simple Python program that provides a menu-driven interface to:

1. Generate a star pattern.
2. Analyze a range of numbers as Even or Odd.
3. Calculate the sum of numbers in a given range.
4. Exit the program.

## 🚀 Features

* ⭐ Generate a triangle star pattern.
* 🔢 Check whether numbers are Even or Odd.
* ➕ Calculate the sum of a range of numbers.
* 🔄 Continuous menu using a `while` loop.
* ❌ Exit option.
* ⚠️ Handles invalid menu choices.

## 🛠️ Requirements

* Python 3.x

No external libraries are required.

## ▶️ How to Run

Save the program as:

```text
pattern_generator.py
```

Then run:

```bash
python pattern_generator.py
```

## 📖 How It Works

### Option 1: Generate a Pattern

Enter the number of rows.

Example:

```text
Enter your choice: 1
Enter the number of rows for the pattern: 5

Pattern:
*
**
***
****
*****
```

### Option 2: Analyze a Range of Numbers

Enter the starting and ending numbers.

Example:

```text
Enter your choice: 2
Enter the start of the range: 1
Enter the end of the range: 5

Number 1 is Odd
Number 2 is Even
Number 3 is Odd
Number 4 is Even
Number 5 is Odd

Sum of all numbers from 1 to 5 is: 15
```

### Option 3: Exit

Selecting `3` exits the program.

```text
Exiting the program. Goodbye!
```
